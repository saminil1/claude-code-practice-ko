# 클로드 코드 비개발자 실무 — 예제 소스

『클로드 코드 비개발자 실무』(이춘곤·Mark, ISC출판) 1권·2권의 **실습용 예제 파일**입니다.

    1권 기본편   코드 없이 시작하는 AI 업무 자동화
    2권 실전편   컨텍스트·하네스·루프와 ISO 심사 자동화

---

## 받는 법 — 사신 책에 맞게

1권만 사셨든 2권만 사셨든, **한 번만 받으시면 됩니다.**
두 권이 함께 쓰는 공통 자료는 양쪽 묶음에 다 들어 있습니다.

| 사신 것 | 받을 것 | 크기 |
|---|---|---|
| **1권 기본편만** | `zips/Vol1-complete.zip` | 1.1 MB |
| **2권 실전편만** | `zips/Vol2-complete.zip` | 3.3 MB |
| **두 권 다** | 오른쪽 위 **Code ▾ → Download ZIP** | 27 MB |
| **한 장만** | `zips/DL-1-07.zip` 처럼 팩 하나 | 수십 KB |

`zips/` 폴더에서 파일 이름을 누르고 오른쪽 **Download** 를 누르시면 됩니다.

책에서 「DL-1-07」이라고 하면 → `zips/DL-1-07.zip`

git 을 쓰신다면:

```bash
git clone https://github.com/saminil1/claude-code-practice-ko.git
```

풀어 놓은 파일도 그대로 있으니, 안을 먼저 들여다보고 받으셔도 됩니다.

## 폴더

책과 같은 순서입니다 — 권이 먼저, 그 안에 장.

```
Vol1/      1권 각 장의 팩      DL-1-04 … DL-1-14
Vol2/      2권 각 장의 팩      DL-2-01 … DL-2-13
Common/    두 권 공통          DL-C02 · DL-C03
zips/      팩별 zip            한 장만 받으실 때
```

| 폴더 | 팩 | 들어 있는 것 |
|---|---|---|
| `Vol1/` | 11 | 사무실 파일 28점, 메일함, 일정표, 엑셀 대장, 계약서·제안서 PDF, 직원명단 |
| `Vol2/` | 12 | 사내 규정집 12종, ISMS 증적, 위탁계약, Odoo 이관자료, 클라우드 설정·로그 |
| `Common/` | 2 | `DL-C02` CLAUDE.md·settings·하네스 시험 · `DL-C03` 런북·변경요청서·설계 캔버스·요구사항 정의서 |

⚠ **1권 1~3장과 `DL-C01`·`DL-C04` 는 폴더가 없습니다.** 그 팩들은 프롬프트·표·용어집처럼
**책 본문에서 나온 것만** 들어 있어 여기 두지 않습니다. 아래를 보십시오.

## 여기 있는 것 / 없는 것

    있는 것    실습 데이터 — 엑셀·문서·이미지·규정집·설정 파일
    없는 것    프롬프트 전문 · 표 모음 · 체크리스트 · 용어집 · 프롬프트 100선

뒤엣것은 **책 본문**입니다. 판권면이 「독자 자료 팩은 이 책을 구입하신 분의 업무 활용을
위한 것」이라고 정하고 있어 공개 저장소에 두지 않습니다.

**팩 전체(본문 포함)는 `isccert.org` 도서 자료실에서 받으실 수 있습니다.**
장 도비라의 QR 코드가 그리로 이어집니다.

## 시작하기 전에

⚠ **원본 업무 파일로 실습하지 마십시오.** 개인정보나 회사 기밀이 든 파일도 쓰지 마십시오.

여기 있는 파일은 전부 실습용으로 지어낸 **가상 자료**입니다 — 회사명·인명·연락처·금액이
실재하지 않습니다. 되돌릴 수 없는 작업(삭제·전송·덮어쓰기)에는 반드시 승인 절차를 두십시오.
판단 기준은 1권 14장에서 다룹니다.
