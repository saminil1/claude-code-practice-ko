# 시험 데이터베이스

이관을 **연습하는 곳**입니다. 여기에만 넣으십시오.

    파일   odoo_시험.sqlite
    표     res_partner · product_template · sale_order · sale_order_line
    상태   비어 있습니다

## 왜 SQLite 인가

실제 Odoo 는 도커 위의 PostgreSQL 로 돕니다. 이 실습에서는 도커를 띄우지
않고도 이관 자체를 해 볼 수 있도록, **표와 열 이름이 같은** SQLite 를
두었습니다. 열 이름·필수 여부·참조 제약은 `Odoo_표구조.md` 와 같습니다.

그래서 이관하는 쪽이 겪는 일은 그대로 일어납니다 — 열을 맞추고, 거래처와
품목이 실재하는지 확인하고, 넣을 수 없는 줄을 목록으로 남기는 일입니다.

## 미리 정의된 값

`uom_uom` 과 `product_category` 에만 값이 들어 있습니다.

    단위   Units · Set · Box · kg · m
    분류   All

기존 자료의 `EA` · `SET` · `BOX` 는 이 목록에 없습니다. 그냥 넣으면
들어가지 않습니다 — 무엇으로 옮길지 정하고 넣으십시오.

## 다시 비우려면

    sqlite3 odoo_시험.sqlite "delete from sale_order_line;
      delete from sale_order; delete from product_template;
      delete from res_partner where ref is null;"
