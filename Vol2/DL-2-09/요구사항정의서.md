# 요구사항 정의서 (초안)

8장에서 작성한 문서입니다. 9장은 이 문서를 패키지 기능과 대조합니다.

작성 2026-08-09 · 초안 · 예산·기간 미정

---

## 1. 배경과 목적

사무기기·소모품 유통업, 직원 20명 안팎, 창고 1개. 견적부터 수금까지를
엑셀 여러 개로 나눠 관리하고 있습니다. 같은 숫자를 여러 파일에 옮겨
적는 과정에서 아래가 반복됩니다.

    · 월말 마감에 3일 소요
    · 부서 간 재고 숫자 불일치 월 5~10건
    · 주문 1건 입력에 5분
    · 재고 조회가 전일 마감 기준

한 곳에 입력하면 관련된 곳이 함께 갱신되도록 하는 것이 목적입니다.

## 2. 범위

견적 · 주문 · 재고 조회 · 출하 · 세금계산서 · 수금 · 반품, 그리고
이들이 쓰는 기준정보(거래처 · 품목).

## 3. 포함하지 않는 업무

명시적으로 제외합니다. 이후 요청이 들어오면 범위 변경으로 처리합니다.

    · 생산 관리 (작업지시 · 자재소요)
    · 회계 전표 자동 생성 및 결산
    · 인사·급여
    · 구매·발주 (재고 부족 알림까지만, 발주는 수동)
    · 모바일 앱
    · 고객 포털 (외부 접속)

## 4. 요구 기능 목록

### 기준정보

    R-01  거래처 등록 — 상호·사업자번호·주소·영업담당을 등록한다
    R-02  거래처 중복 방지 — 사업자번호가 같으면 등록 단계에서 막는다
    R-03  거래 종료 거래처 숨김 — 목록에서 보이지 않되 과거 이력은 남는다
    R-04  품목 등록 — 품번·품목명·규격·단위·기준단가를 등록한다
    R-05  단종 품목 표시 — 신규 주문에서 고르지 못하게 한다
    R-06  예전 품번 조회 — 옛 품번으로도 품목을 찾을 수 있다

### 견적

    R-07  견적서 작성 — 거래처·품목·수량·단가로 견적을 만든다
    R-08  견적서 출력·발송 — PDF 로 뽑아 메일로 보낸다
    R-09  견적 → 주문 전환 — 견적을 다시 입력하지 않고 주문으로 바꾼다

### 주문

    R-10  주문 등록 — 거래처·품목·수량·단가·납기를 입력한다
    R-11  주문 변경 이력 — 수량·단가를 고치면 누가 언제 고쳤는지 남는다
    R-12  주문 취소 — 줄을 지우지 않고 취소 상태로 남긴다
    R-13  신규 거래처 첫 거래 승인 — 팀장 승인 전에는 출하로 넘어가지 않는다
    R-14  미수 거래처 추가 주문 승인 — 미수금이 있으면 승인을 거친다
    R-15  거래처별 여신 한도 초과 시 주문 자동 보류

### 재고·출하

    R-16  실시간 재고 조회 — 당일 출고분이 즉시 반영된다
    R-17  출하 지시 — 주문에서 출하 지시를 만든다
    R-18  부분 출하 — 재고가 일부만 있을 때 나눠 출하한다
    R-19  잔량 자동 이월 — 부분 출하의 잔량이 자동으로 남아 추적된다
    R-20  거래명세서 출력
    R-21  재고 실사 반영 — 실물과 장부가 다를 때 조정하고 이력을 남긴다

### 세금계산서·수금

    R-22  세금계산서 발행 — 출하 건에서 세금계산서를 만든다
    R-23  월합계 세금계산서 — 월단위로 묶어 한 장으로 발행한다 (12개 거래처)
    R-24  수정세금계산서 — 발행 후 금액 정정
    R-25  입금 등록 — 통장 입금을 거래처·전표에 맞춘다
    R-26  부분 입금 처리 — 한 건을 나눠 입금받는다
    R-27  미수 현황 조회 — 거래처별 미수금과 경과일

### 반품

    R-28  반품 접수 — 반품전표를 만들고 재고를 되돌린다
    R-29  교환 처리 — 반품과 재출하를 한 건으로 묶는다

### 공통

    R-30  월말 마감 집계 — 매출·미수·재고를 한 번에 뽑는다
    R-31  거래처 등급·수량 구간·계절 계수를 반영한 단가 자동 산정
    R-32  권한 관리 — 영업·창고·경리가 서로의 화면을 보지 못한다

## 5. 데이터 요구

기존 엑셀 3종을 옮깁니다.

| 자료 | 건수 |
|---|---|
| 거래처 | 1,482 |
| 품목 | 2,105 |
| 주문내역 | 8,940 |

옛 자료의 형식이 고르지 않습니다 — 날짜 표기 3종 혼재, 금액에 쉼표·"원"
혼재, 사업자번호 하이픈 유무 혼재, 상호에 "(주)"·"㈜"·"주식회사" 혼재.

## 6. 성공 기준

    · 월말 마감 소요: 현재 3일 → 목표 1일
    · 재고 조회 시점: 현재 전일 기준 → 목표 실시간
    · 부서 간 재고 숫자 불일치: 현재 월 5~10건 → 목표 0건
    · 주문 입력 소요: 현재 건당 5분 → 목표 2분

현재 수치는 담당자 체감입니다. **실측이 필요합니다.**

## 7. 검토 필요

말하지 않았으나 통상 함께 검토하는 항목입니다. **요구에 넣지
않았습니다.** 필요 여부를 판단해 주십시오.

    1. 다중 창고 관리 (창고가 하나 이상입니까?)
    2. 세금계산서 국세청 연동
    3. 승인 권한의 대결 처리 (승인자 부재 시)
    4. 데이터 보존 기간과 아카이브 정책
    5. 다중 창고 간 이동 시 재고 실사 처리
