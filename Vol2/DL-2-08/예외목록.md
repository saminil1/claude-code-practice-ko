# 예외 목록

정상 흐름에서 벗어나는 경우들입니다. 8.1 인터뷰의 2~4차 문답에서
나온 것을 모았습니다.

## 주문 단계

| 예외 | 얼마나 | 지금 처리 |
|---|---|---|
| 구두·전화 주문 | 전체의 약 30% | 저녁에 몰아서 대장에 입력 |
| 주문 후 수량 변경 | 월 10건 안팎 | 대장을 덮어씀 — 이력이 안 남음 |
| 주문 취소 | 월 3~5건 | 대장에서 줄을 지움 |
| 같은 거래처가 다른 이름으로 | 상시 | "(주)" 유무로 두 줄이 됨 |

## 재고·출하 단계

| 예외 | 얼마나 | 지금 처리 |
|---|---|---|
| 부분 출하 | 월 15건 안팎 | 잔량을 비고란에 손으로 적음 |
| 잔량 이월 누락 | 월 1~2건 | 거래처가 연락해 와야 알게 됨 |
| 긴급 출하 (당일) | 주 2~3건 | 창고에 전화, 지시서 없이 나감 |
| 창고 실물과 장부 불일치 | 월 5~10건 | 실사 후 장부를 맞춤 |

## 세금계산서·수금 단계

| 예외 | 얼마나 | 지금 처리 |
|---|---|---|
| 월합계 발행 요청 거래처 | 12곳 | 경리가 월말에 손으로 합산 |
| 발행 후 금액 정정 | 월 2~3건 | 수정세금계산서 발행 |
| 부분 입금 | 월 5건 안팎 | 통장 대사 엑셀에 나눠 적음 |
| 입금자명이 상호와 다름 | 월 10건 안팎 | 경리가 기억으로 맞춤 |
| 미수 장기화 | 상시 20곳 안팎 | 영업이 개별 독촉 |

## 반품·기타

| 예외 | 얼마나 | 지금 처리 |
|---|---|---|
| 반품 | 월 8건 안팎 | 반품전표 작성, 재고는 수기 가산 |
| 교환 (반품+재출하) | 월 2~3건 | 반품과 신규 주문 두 건으로 나눠 적음 |
| 단종 품목 주문 | 가끔 | 영업이 대체품을 안내 |
| 거래처 폐업 | 연 5~10곳 | 대장에 그대로 남아 있음 |

## 이 목록에서 걸리는 것

    · 이력이 남지 않는 예외가 많습니다 (수량 변경 · 취소 · 승인)
    · 사람의 기억에 기대는 처리가 있습니다 (입금자명 대사)
    · 예외 건수를 세어 본 적이 없어 위 숫자는 담당자 체감입니다
      → 실제 수치는 확인이 필요합니다
