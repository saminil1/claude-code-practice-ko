# settings.json 권한 설계 — 개념 예시
# 실제 형식은 사용 중인 판본의 공식 문서를 확인하십시오.

읽기 허용:  ./원본/  ./증적/  ./작업/
쓰기 허용:  ./작업/          ← 한 곳만
쓰기 금지:  ./원본/  ./증적/

실행 금지:  삭제 명령 전체
            파일 이동 명령
            외부 전송 명령

승인 필요:  파일 5개 이상을 한 번에 다루는 작업
            기존 파일 덮어쓰기
            외부 네트워크 접근

# ── 설계 3원칙 ──
#  1) 기본은 금지 — 열어 준 것만 되게 한다
#  2) 쓰기는 한 곳만
#  3) 되돌릴 수 없으면 승인

# ── 설정 범위 (2권 2.10) ──
#  개인      ~/.claude/settings.json
#  프로젝트  .claude/settings.json          (형상관리 포함)
#  개인 재정의 .claude/settings.local.json   (형상관리 제외)
#  우선순위  조직 관리 > 명령줄 > 개인재정의 > 프로젝트 > 개인
