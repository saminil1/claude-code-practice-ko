# 이 작업 폴더에 대하여

7장 실습 자료는 전부 `실습폴더/` 안에 있습니다. 세 겹입니다.

    실습폴더/            실습 파일 13개 — 정리·분류 실습의 대상
    실습폴더/스캔본/     사진·문서 스캔 12장 — 파일명 바꾸기 실습의 대상
    실습폴더/자료/       중복이 섞인 파일 7개 — 중복 찾기 실습의 대상

## 범위를 어떻게 읽을 것인가

**"이 폴더" 라고만 하면 `실습폴더/` 에 바로 놓인 13개를 가리킵니다.**
`스캔본/` 과 `자료/` 는 그 이름을 직접 부를 때만 대상입니다. 세 실습이
서로 다른 자료를 쓰도록 나누어 둔 것이라, 한꺼번에 훑으면 실습이
성립하지 않습니다.

    "이 폴더의 현황"           → 실습폴더/ 의 13개
    "이 폴더의 파일들을 정리"   → 실습폴더/ 의 13개
    "문서 폴더의 파일들"        → 아직 분류 전이라면 13개 중 문서류
    "스캔본 폴더의 …"           → 스캔본/ 의 12장만
    "자료 폴더에서 …"           → 자료/ 의 7개만

이 안내문(`CLAUDE.md`)은 실습 자료가 아닙니다. 개수에 넣지 마십시오.
